# Student Portal Management System

## 📌 Project Overview

The Student Portal Management System is a full-stack web application developed using React.js, Java Spring Boot, REST APIs, and MySQL. It helps manage student information through a simple and user-friendly interface.

The application supports CRUD (Create, Read, Update, and Delete) operations, allowing users to add new student records, view student details, update existing information, and delete records.

## ✨ Features

- Add new student details
- View all student records
- Search and retrieve student information
- Update existing student details
- Delete student records
- Store and manage student data using MySQL
- Connect the React frontend with the Spring Boot backend using Axios
- Perform database operations using Spring Data JPA
- Handle HTTP requests through REST APIs

## 🏗️ Project Architecture

The application follows a frontend-backend architecture:

- **React.js:** Provides the user interface for managing student records.
- **Axios:** Sends HTTP requests from the frontend to the backend.
- **Spring Boot:** Implements REST API endpoints and application logic.
- **Spring Data JPA:** Handles database operations.
- **MySQL:** Stores student information persistently.

## ⚙️ How to Run the Project

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Configure MySQL
- Create the required MySQL database.
- Update the database URL, username, and password in the Spring Boot `application.properties` file.

### 3. Run the Backend
- Open the Spring Boot project in Eclipse.
- Start the Spring Boot application.
- Ensure the configured backend port is available.

### 4. Run the Frontend
- Open the React project folder in Visual Studio Code.
- Install the dependencies:

```bash
npm install
```

- Start the React development server:

```bash
npm run dev
```

- Open the local URL displayed in the terminal, usually `http://localhost:5173`.

## 🔗 API Integration

The frontend communicates with the Spring Boot backend using Axios and REST APIs.

The application supports:
- **POST** – Create a student record
- **GET** – Retrieve student records
- **PUT** – Update a student record
- **DELETE** – Delete a student record

The exact API endpoints depend on the backend controller configuration.
